  • commit → push → MR 到 adata-baseline
  • 合并后部署 CVM 走查（需你确认「部署」）

部署到 adata 时的连接机制（补充说明）：不经过快照，是运行时直连。代码带 bound_db_names 上传 → adata 平台自动注入数据库连接地址到容器环境变量 → 适配层用内置默认账号密码补全 → 容器启动直连 adata 真实生产 MySQL → 运行时自动把代码里的 SQLite 写法翻译成 MySQL 写法 → 建表逻辑幂等（表存在则跳过），部署不会清空或重建任何已有数据。
