方案要点速记

  • 代码只有一份，用 Git 分支 adata-baseline 承载，物理上不存在两个版本
  • 三个环境（本地 macOS / CVM 走查 / adata 生产）差异只体现在环境变量
  • 数据单向流动：adata 是唯一真相源，快照只流向 CVM 和本地，绝不回流
  • 代码单向流动：本地开发 → CVM 走查验收 → adata 部署，不可跳过走查
